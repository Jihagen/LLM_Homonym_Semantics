# Data dictionary

Data version 1.0.0. Every file below is listed in
[`release_manifest.json`](release_manifest.json) with its size, SHA-256
checksum and, for tables, its row count and column names.
`python -m scripts.validate_release` checks the files against that manifest.

Licence: CC BY 4.0 (see [`../LICENSE-DATA`](../LICENSE-DATA)).

```
data/
  profiling_sentences.json      pipeline input: sense-labelled profiling sentences
  paired_sentences.json         pipeline input: carriers with a resolving clause before/after the homonym
  garden_path_sentences.json    pipeline input: context-conflict items with matched controls
  stimuli/                      the same stimuli as flat CSV tables (derived, never edited by hand)
  processed/                    result tables
  processed/example_states/     three small single-layer hidden-state examples
  release_manifest.json         also lists the website exports in ../web_export/
```

The website exports are documented in [`../web_export/README.md`](../web_export/README.md).
Two of them, `geometry_by_layer.json` and `garden_path_landscapes.json`, contain
display coordinates: three-dimensional PCA projections of hidden states, made
for plotting. They are not analysis results. Every GDV, adequacy and margin
value stored next to them is a full-space value from the tables below.

The coordinates in `geometry_by_layer.json` are **within-layer standardised
display coordinates in one shared PCA basis**: each layer is centred and
divided by its own within-sense spread, and one PCA basis per model and homonym
is used for all layers. They support inspecting cluster separation across
depth. Absolute cloud size is not comparable between layers. Full-space GDV,
adequacy and margins remain the analysis metrics.

## Conventions

- **`word`** is one of `bank, bark, bat, crane, spring, match, pitch`.
- **`sense`** is `0` or `1`; the meaning of each is given in
  `stimuli/homonyms.csv`.
- **`model`** is the Hugging Face repository id with `/` replaced by `_`
  (e.g. `Qwen_Qwen2.5-7B`). `processed/models.csv` maps it to the repository id,
  a display name and the architecture.
- **`arch_type`** is `encoder` (bidirectional) or `decoder` (causal).
- **Layer indices** count hidden states: `0` is the embedding output and the
  last index is the final layer. A model with 24 transformer blocks has 25
  hidden states (`0`–`24`).
- **Raw margin** (`*_raw`, `M_l_raw`, `MeanMarginRaw`): Euclidean distance to
  the centroid of the other sense minus distance to the centroid of the
  reference sense, in the model's hidden-state units. Not comparable across
  models or layers.
- **Normalised margin** (`*_norm`, `M_l_norm`, `MeanMarginNorm`): the raw
  margin divided by the distance between the two sense centroids.
  Dimensionless, in [−1, 1]; 0 is the nearest-centroid decision boundary.
- **Sign.** For sense-labelled observations ("correct-sense margin") positive
  means closer to the intended sense. Columns prefixed `signed_` (H0) are
  instead positive toward sense 0 and negative toward sense 1.
- **Adequate** means raw margin > 0 (the observation is on the correct side).
  A fraction adequate is a proportion in [0, 1].
- **GDV** (Generalized Discrimination Value): dimensionless; more negative
  means stronger separation of the two sense clusters.
- Result tables are text-identical copies of the pipeline's CSV output. The
  only edits are added key columns (`model`, `word`) where one pipeline file per
  model or word was concatenated. Rounding is whatever the pipeline wrote.
- Booleans are `True`/`False`. Empty cells mean "not applicable".

## Pipeline input files

| File | Structure |
|---|---|
| `profiling_sentences.json` | list of `{word, semantic_group_id, sense_label, examples[20]}`; `semantic_group_id` is the sense. Also contains the excluded word *light*. |
| `paired_sentences.json` | `{word: [{id, sentence, condition, sense, carrier}]}` |
| `garden_path_sentences.json` | `{word: [{id, sentence, primed_sense, correct_sense, resolution_word, matched_control_sentence, design_note?}]}` |

All sentences were authored for this study.

## Stimulus tables (`stimuli/`)

Generated by `python -m scripts.build_stimulus_tables` from the three files
above. They contain the seven study words only.

### `homonyms.csv` — 14 rows (word × sense)

| Column | Meaning |
|---|---|
| `word` | the homonym |
| `sense` | 0 or 1 |
| `sense_label` | description of the sense, e.g. "River / embankment" |
| `short_label` | one-word label used in figures, e.g. "river" |
| `n_profiling_sentences` | number of profiling sentences for this sense (20) |

### `profiling_sentences.csv` — 280 rows

Unambiguous sentences that fix each sense. They define the sense centroids
used by every analysis and are the observations of H1 and H2.

| Column | Meaning |
|---|---|
| `sentence_id` | `<word>_profile_s<sense>_<nn>` |
| `word`, `sense`, `sense_label` | as above |
| `profile_index` | 0–39 within a word; the position of the sentence in the pipeline's activation cache and the value of `held_out_sentence_index` in `processed/h1_nested_loo.csv` |
| `sentence` | the sentence |

### `carrier_contexts.csv` — 42 rows (H0)

| Column | Meaning |
|---|---|
| `carrier_id` | `<word>_carrier_<nn>` or `<word>_bare` |
| `word` | the homonym |
| `condition` | `ambiguous_carrier`: a short sentence that does not decide between the senses (5 per word). `bare_word`: the homonym alone (1 per word). |
| `text` | the text given to the model |

### `paired_context_sentences.csv` — 140 rows (H3, H4)

Each ambiguous carrier is extended with a clause that resolves it toward one
sense. The clause is placed before the homonym (L) or after it (R). The L and
R sentences of a pair combine the same carrier and the same clause in a
different order.

| Column | Meaning |
|---|---|
| `sentence_id` | `<word>_<L or R>_<nn>` |
| `word` | the homonym |
| `pair_id` | `<word>_<nn>`; links the L and R version of one item |
| `condition` | `L` or `R` |
| `resolver_position` | `before_homonym` (L) or `after_homonym` (R) |
| `sense` | the sense the resolving clause supports |
| `sense_label_short` | short label of that sense |
| `carrier_id`, `carrier` | the ambiguous carrier the sentence is built on |
| `sentence` | the full sentence |

Each word has 5 carriers × 2 senses × 2 positions = 20 sentences. H4 uses the
R sentences only.

### `conflict_items.csv` — 98 rows (H5)

Each item has two paths that share everything from the homonym onward:

- the **conflicting** path, whose opening context primes one sense and whose
  later context resolves to the other;
- the **coherent control**, whose opening context already supports the sense
  the sentence resolves to.

| Column | Meaning |
|---|---|
| `item_id` | `<word>_gp_<nn>` |
| `word` | the homonym |
| `primed_sense` | sense supported by the opening context of the conflicting sentence |
| `correct_sense` | sense supported by the resolving context (the final reading) |
| `direction` | `<primed>_to_<correct>`; each word has 7 items per direction |
| `primed_sense_label_short`, `correct_sense_label_short` | short labels |
| `resolution_word` | first word after the homonym that is intended to decide the sense |
| `conflicting_sentence` | full conflicting sentence |
| `coherent_control_sentence` | full matched control sentence |
| `sentinel` | the fixed readout token appended to every prefix (`probe`) |
| `conflicting_prime_prefix` | text up to but excluding the homonym, then a blank line and the sentinel |
| `conflicting_homonym_prefix` | text through the homonym, then the sentinel |
| `conflicting_resolution_prefix` | text through the resolution word, then the sentinel |
| `coherent_control_resolution_prefix` | control sentence through the resolution word, then the sentinel |
| `resolver_only_text` | the resolution word alone, then the sentinel |
| `design_note` | author's note on an item, usually empty |

The five prefix columns are the exact strings given to the models. Each is run
as a separate forward pass and the hidden state is read at the sentinel.

## Result tables (`processed/`)

Built by `python -m scripts.build_release_data` from a finished pipeline run.
"Cell" means one model × word combination (56 cells).

### Reference

**`models.csv`** — 8 rows. `model` (key), `hf_repo_id`, `display_name`,
`arch_type`, `n_hidden_states` (embedding output plus blocks),
`last_layer_index`, `hf_revision` (commit of the weights used).

### H0 — baseline sense lean

**`h0_carrier_lean.csv`** — 280 rows (cell × carrier).

| Column | Meaning |
|---|---|
| `model`, `word`, `carrier` | keys; `carrier` matches `carrier_contexts.csv` `text` |
| `signed_M_l_word_alone_raw`, `_norm` | lean of the bare word (same for all carriers of a cell) |
| `signed_M_l_carrier_raw`, `_norm` | lean of the homonym in this carrier |
| `signed_carrier_shift_raw`, `_norm` | carrier lean minus bare-word lean |
| `prior_direction` | `sense_0`, `sense_1` or `tie` |
| `abs_norm_gt_0p3` | whether the normalised carrier lean exceeds 0.3 in magnitude (descriptive threshold) |
| `threshold_status` | constant label marking the threshold as descriptive |
| `layer` | layer read (the cell's H1-selected layer) |

**`h0_summary.csv`** — 56 rows (cell). `n_independent_carriers`,
bare-word lean (`signed_M_l_word_alone_*`), `mean_signed_M_l_carrier_*`,
`mean_abs_M_l_carrier_norm`, `mean_abs_carrier_shift_raw`,
`direction_consistency` (larger share of carriers leaning the same way, 0.5–1),
`n_abs_norm_gt_0p3`, `threshold_status`, `layer_used`.

### H1 — layer depth

**`h1_layer_profiles.csv`** — 1,708 rows (cell × layer). The layer-wise sense
separation curves.

| Column | Meaning |
|---|---|
| `model`, `word`, `Layer` | keys |
| `MeanMarginRaw`, `MeanMarginNorm` | mean leave-one-sentence-out margin over the 40 profiling sentences |
| `FractionAdequate` | share of the 40 sentences on the correct side |
| `MeanMarginSense0Raw`, `MeanMarginSense1Raw` | mean raw margin per sense |
| `CentroidMode` | `leave_one_out`: each sentence is scored against centroids estimated without it |
| `GDV` | Generalized Discrimination Value of the layer |

**`h1_layer_selection_summary.csv`** — 56 rows (cell).

| Column | Meaning |
|---|---|
| `n_layers` | number of hidden states |
| `best_layer_M`, `best_layer_depth` | selected layer: highest `FractionAdequate` on the full profile, ties broken by `MeanMarginNorm`, layer 0 excluded; and its relative depth (layer / last layer index) |
| `best_layer_selection_basis` | how `best_layer_M` was chosen |
| `mean_M_best_raw/_norm`, `mean_M_last_raw/_norm` | mean margin at that layer and at the last layer |
| `frac_adeq_best`, `frac_adeq_last` | fraction adequate at that layer and at the last layer |
| `nested_frac_selected`, `nested_frac_last` | held-out fraction adequate when the layer is chosen inside each leave-one-sentence-out fold, and at the last layer |
| `nested_mean_M_norm_selected`, `nested_mean_M_norm_last` | corresponding mean normalised margins |
| `nested_modal_selected_layer`, `nested_n_outer_folds` | most frequently chosen layer; number of folds (40) |
| `gdv_best_layer` | layer with the most negative GDV (layer 0 excluded) |
| `layers_agree` | whether `best_layer_M` equals `gdv_best_layer` |

**`h1_nested_loo.csv`** — 2,240 rows (cell × held-out sentence).
`held_out_sentence_index` (= `profile_index`), `sense`, `selected_layer`,
`last_layer`, and for both layers the held-out `M_raw_*`, `M_norm_*`,
`adequate_*`.

**`gdv_model_layer_summary.csv`** — 244 rows (model × layer). `GDV` averaged
over the seven words and `MeanRank`, the mean rank of the layer by GDV across
words (1 = best).

### H2 — cross-word layer selection

**`h2_leave_one_word_out.csv`** — 56 rows (model × held-out word). A layer is
chosen on the other six words by one of four strategies and evaluated on the
held-out word. Strategy suffixes: `gdv` (most negative GDV), `supervised`
(highest adequacy), `last` (final layer), `oracle` (best layer for the
held-out word itself). Per strategy: `<s>_selected_layer`, `mean_M_raw_<s>`,
`mean_M_norm_<s>`, `fraction_adequate_<s>`, `layer_distance_to_oracle_<s>`
(layers), `relative_depth_<s>`, `fraction_regret_to_oracle_<s>` (oracle
adequacy minus this strategy's), `held_out_adequacy_rank_<s>` (rank of the
chosen layer among all layers, 1 = best), `within_2_layers_of_oracle_<s>`.

**`h2_strategy_summary.csv`** — 8 rows (model). Means of the above over the
seven held-out words, plus `gdv_minus_last_fraction` and
`supervised_minus_last_fraction`.

**`geometry_inference.csv`** — 12 rows. Bootstrap intervals for the H1 and H2
contrasts: `analysis`, `contrast`, `scope` (`all`, `encoder`, `decoder`),
`n_models`, `n_words`, `mean_effect`, `ci95_low`, `ci95_high`,
`bootstrap_unit`, `n_bootstrap`, `seed`.

### H3 — context before or after the homonym

All margins are read at the homonym token.

**`h3_sentence_level.csv`** — 1,120 rows (model × paired sentence).
`sentence_id`, `pair_id`, `condition`, `sense`, `carrier`, `M_l_raw`,
`M_l_norm`, `adequate`, `layer`.

**`h3_pair_differences.csv`** — 560 rows (model × pair). `M_norm_L`,
`M_norm_R`, `delta_M_norm_L_minus_R`, `adequate_L`, `adequate_R`,
`delta_adequate_L_minus_R`.

**`h3_aggregate.csv`** — 112 rows (cell × condition). `n`, `mean_M_l_raw`,
`mean_M_l_norm`, `frac_adequate`, `layer_used`.

**`h3_paired_summary.csv`** — 8 rows (model). Mean L−R difference in margin
and in fraction adequate with 95% word-bootstrap intervals, and three
construction checks for decoders (`decoder_R_*`, `max_abs_mirrored_R_margin_sum`):
in the R condition a causal model has seen only the ambiguous carrier at the
homonym, so the two senses of a carrier must give mirrored margins.

**`h3_architecture_interaction.csv`** — 1 row. Decoder L−R effect minus
encoder L−R effect with a 95% interval from a crossed model-by-word bootstrap.

### H4 — decodability at the homonym and at the sentence end

R-condition sentences only. "Target" is the homonym position, "final" the
sentence-final period. "Local" margins use centroids estimated at the same
position.

**`h4_sentence_level.csv`** — 560 rows (model × R sentence).

| Column | Meaning |
|---|---|
| `sentence_id`, `sentence`, `carrier`, `sense` | the item |
| `final_surface_unit` | the token read at the sentence end (`.`) |
| `target_local_margin_raw/_norm`, `target_local_adequate` | margin at the homonym against homonym-position centroids |
| `final_local_margin_raw/_norm`, `final_local_adequate` | margin at the period against final-position centroids |
| `final_cross_position_margin_raw/_norm`, `final_cross_position_adequate` | diagnostic: period state against homonym-position centroids |
| `local_transition` | `adequate_at_both`, `inadequate_to_adequate`, `adequate_to_inadequate`, `inadequate_at_both` |
| `layer` | layer read |

**`h4_aggregate.csv`** — 56 rows (cell). Means and fractions of the above,
the four transition counts (`n_target_*_final_*`), the conditional
probabilities `p_final_adequate_given_target_inadequate` and
`p_final_inadequate_given_target_adequate` with Wilson interval bounds
(`*_ci_low`, `*_ci_high`), `layer_used`, and two constant labels
(`primary_estimand`, `cross_position_status`).

### H5 — revision under conflicting context

Every margin is a correct-sense margin (positive = toward the sense the
sentence resolves to), read at the sentinel after a separate forward pass of
the prefix.

**`h5_sentence_level.csv`** — 784 rows (model × item).

| Column | Meaning |
|---|---|
| `sentence_id` | `item_id` in `stimuli/conflict_items.csv` |
| `sentence`, `primed_sense`, `correct_sense`, `direction`, `resolution_word`, `sentinel` | the item |
| `prime_prefix`, `homonym_prefix`, `resolution_prefix` | the three texts that were run |
| `prime_token_count`, `homonym_token_count`, `resolution_token_count` | length of each prefix in model tokens |
| `prime_correct_margin_*`, `homonym_correct_margin_*`, `resolution_correct_margin_*` | margin after the prime, after the homonym, after the resolver (conflicting path) |
| `matched_control_correct_margin_*` | margin after the resolver on the coherent control path |
| `resolver_isolated_correct_margin_*` | margin for the resolution word alone |
| `delta_homonym_minus_prime_norm`, `delta_resolution_minus_homonym_norm`, `delta_resolution_minus_prime_norm` | movement between stages; the second is the main "update" measure |
| `delta_resolution_minus_isolated_resolver_norm` | conflicting endpoint minus resolver-only baseline |
| `garden_path_cost_vs_matched_control_norm` | conflicting endpoint minus coherent-control endpoint (negative = conflict leaves the state further from the final sense) |
| `primed_at_homonym` | margin after the homonym is below 0 (on the primed side) |
| `resolved_correct` | margin after the resolver is above 0 |
| `successful_primed_to_correct_transition` | both of the above: the state crossed the decision boundary |
| `human_prime_strength`, `human_resolution_clarity` | empty; no human norms were collected |
| `layer` | layer read (the cell's H1-selected layer) |
| `analysis_status` | constant label from the stimulus audit |
| `<stage>_state_thr_<t>` | `correct`, `primed` or `boundary`: the side of the state when a margin within ±t (0.0, 0.1, 0.3) counts as undecided |

**`h5_aggregate.csv`** — 56 rows (cell). `n_items`, `n_primed_at_homonym`,
`n_successful_primed_to_correct`, `p_resolved_correct_given_primed_at_homonym`,
means of the stage margins and deltas, `layer_used`.

**`h5_architecture_exploratory.csv`** — 3 rows. Post-hoc decoder-minus-encoder
contrasts (`update`, `resolver_endpoint`, `conflict_minus_matched_control`)
with crossed-bootstrap intervals.

**`h5_design_audit.csv`** — 8 rows (word, including the excluded *light*).
Balance and completeness of the H5 stimuli.

**`cross_hypothesis_associations.csv`** — 5 rows. Post-hoc Pearson and
Spearman correlations between H0 lean and H1/H5 outcomes across cells;
p-values are uncorrected.

### Exploratory extension (Q4; not in the report)

Q4 repeats the layer profile on the L-condition paired sentences, where the
resolving clause precedes the homonym so that causal models have seen it.

**`q4_layer_curves.csv`** — 1,708 rows (cell × layer). `homonym` (= word),
`architecture`, `layer`, `relative_depth`, `adequacy`, `mean_margin`
(normalised), `is_candidate`, `peak_adequacy`, `best_layer`.

**`q4_candidate_layers.csv`** — 792 rows. The candidate layers of each cell:
adequacy within 0.05 of the cell's peak and at least 0.6.

**`q4_h1_layer_shift.csv`**, **`q4_h5_outcome_comparison.csv`** — 56 rows each
(cell). How the H1-selected layer relates to the Q4 candidates, and how H5
outcomes differ at the best Q4 candidate layer.

**`h5_by_layer_aggregate.csv`** — 792 rows; **`h5_by_layer_sentence_level.csv`**
— 11,088 rows. H5 repeated at every Q4 candidate layer. Columns as in the H5
tables. The sentence-level table omits `sentence`, `prime_prefix`,
`homonym_prefix` and `resolution_prefix`; join on `sentence_id` to recover
them.

### Sample trajectories

**`trajectory_h3_context.csv`** — 40 rows; **`trajectory_h5_revision.csv`** —
28 rows. Per-item margins for *bank* in RoBERTa-large and Qwen2.5-7B at each
stage, as plotted in `figures/supplementary/`. H3 stages: homonym position and
sentence-final position. H5 stages: prime, homonym, resolution.

The only hidden states in the release, 2.6 MB in total.

| File | Arrays |
|---|---|
| `h2_geometry_Qwen_Qwen2.5-7B_bat_layer{3,26}.npz` | `X` (40 × 3584) homonym states of the 40 *bat* profiling sentences, `labels` (sense), `sentences`, `layer` |
| `h3_context_trajectory_<model>_bank.npz` | `profile_homonym_H`, `profile_resolved_H` (40 × d), `profile_senses`, `item_homonym_H`, `item_resolved_H` (20 × d), `item_conditions`, `item_senses`, `item_ids`, `layer` |
| `h5_revision_trajectory_<model>_bank.npz` | `profile_H` (40 × d) sentinel states of the profiling sentences, `profile_senses`, `stage_H` (42 × d) sentinel states of 14 items × 3 stages, `stage_item_index`, `stage_name`, `item_ids`, `layer` |
